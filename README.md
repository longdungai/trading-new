* ⚡ **Cập Nhật Giá Thời Gian Thực Liên Tục (2.5 Giây):** Tự động đồng bộ biến động giá, đỉnh/đáy 24h và khối lượng khớp lệnh; kết nối **Binance WebSocket** trực tiếp từng giây (tick-by-tick).
* 📈 **Biểu Đồ Kỹ Thuật Siêu Mượt (60 FPS):** Tích hợp TradingView Lightweight Charts với hơn 15 chỉ báo (EMA Ribbon 20/50/200, SuperTrend, Bollinger Bands, RSI 14, MACD Histogram, Tự động vẽ Hỗ trợ / Kháng cự & Fibonacci).
* 🎯 **Trung Tâm Chiến Lược Đề Xuất (Strategy Hub):** Đánh giá đồng thời 7 chiến lược định lượng & Smart Money Concepts (SMC), tính toán mốc **Entry Zone**, **Cắt Lỗ (Stop Loss)**, **3 Mốc Chốt Lời (TP1, TP2, TP3)**, **Tỉ lệ Risk:Reward** và **Xác Suất Thắng (%)**.

* 📱 **Giao Diện Chuẩn Mobile & PWA:** Tối ưu hóa 100% cho màn hình cảm ứng điện thoại với thanh điều hướng đáy (Bottom Navigation), thanh chọn khung giờ 1 chạm và hỗ trợ cài đặt thành App Native trên iPhone & Android.

## 🎯 Trung Tâm 7 Chiến Lược Giao Dịch Định Lượng

1. **📈 SuperTrend + EMA Golden Ribbon:** Bám xu hướng lớn, lọc nhiễu qua SuperTrend và cặp đường trung bình EMA 20/50/200.
2. **💎 Smart Money (SMC) Order Blocks:** Bắt nhịp quét thanh khoản (Liquidity Sweep) và khối lệnh cá mập tổ chức.
3. **📐 Fibonacci Golden Pocket 0.618:** Đón sóng hồi chuẩn mực tại vùng tỉ lệ vàng 61.8% – 65% để tối ưu hóa R:R.
4. **🎯 RSI Mean Reversion (30/70):** Khai thác sự cạn kiệt lực bán tại vùng quá bán (< 30) và chốt lời khi quá mua (> 70).
5. **💥 Bollinger Bands Squeeze & Breakout:** Bắt trọn con sóng bùng nổ biến động sau giai đoạn nén dải hẹp.
6. **⚡ MACD Momentum Expansion:** Đo lường gia tốc giá qua Histogram và điểm giao cắt Zero-Lag.
7. **🛡️ Phá Vỡ & Retest Hỗ Trợ/Kháng Cự:** Giao dịch theo các ngưỡng cản cứng nhiều lần chạm bật lịch sử.

## 🛠️ Hướng Dẫn Cài Đặt & Khởi Chạy Nhanh

### 1. Khởi chạy trên máy tính:
```bash
# 1. Clone mã nguồn về máy
git clone https://github.com/longdungai/trading-new.git
cd trading-new

# 2. Cài đặt các thư viện phụ thuộc
npm install

# 3. Khởi chạy Server phát triển
npm run dev
```
👉 Mở trình duyệt tại: **`http://localhost:5173`**

Hoặc nhấp đúp chuột vào file **`start.bat`** trên Windows để mở ngay lập tức!

### 2. Triển khai miễn phí lên Vercel:
1. Đăng nhập vào [Vercel.com](https://vercel.com) bằng tài khoản GitHub.
2. Bấm **"Add New..."** $\to$ Chọn **"Project"** $\to$ **Import** kho `trading-new`.
3. Bấm **"Deploy"** (Cấu hình proxy đã được cài đặt tự động trong `vercel.json`).

### 3. Tự động đồng bộ lên GitHub & Vercel sau khi sửa code:
- Nhấp đúp chuột vào file **`update.bat`** để tự động gom file, tạo commit và đẩy lên GitHub trong 1 giây!

## 📱 Hướng Dẫn Cài App Trên Điện Thoại (iOS & Android)

### 🍏 Đối với iPhone & iPad (Safari):
1. Mở Safari truy cập đường link web của bạn (hoặc link nội bộ `http://192.168.1.89:5173`).
2. Bấm nút **Chia sẻ (Share)** ở thanh dưới Safari $\to$ Chọn **"Thêm vào Màn hình chính" (Add to Home Screen)**.
3. Ứng dụng sẽ hiển thị toàn màn hình như một App Native tải từ App Store.

### 🤖 Đối với Android (Google Chrome):
1. Mở Chrome truy cập link web.
2. Bấm nút **Menu (3 dấu chấm góc trên)** $\to$ Chọn **"Cài đặt ứng dụng"** hoặc **"Thêm vào màn hình chính"**.
